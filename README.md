# Extensão - Qualidade de Software

Este repositório foi criado para documentar os testes realizados durante o projeto de Extensão da disciplina de Qualidade de Software.

## Sistema testado

SIFIT

## Objetivo

Realizar testes no sistema, documentando os cenários executados, resultados encontrados, bugs identificados e evidências dos testes.

## Documentação

Os testes serão organizados em:

- Análise de requisitos
- Plano de testes
- Cenários de testes
- Relatório de bugs
- Relatório final dos testes
- Evidências
