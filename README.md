## Sistema testado

**SIFIT** — sistema de gestão para academias.

## Objetivo

Aplicar os conhecimentos de Qualidade de Software por meio do planejamento, execução e documentação de testes, verificando o comportamento do sistema e registrando os resultados e possíveis falhas encontradas.

## Organização da documentação

A documentação do projeto contempla:

- Análise de requisitos;
- Plano de testes;
- Cenários e casos de teste;
- Evidências das execuções;
- Relatório de bugs;
- Relatório final dos testes.

## Registro dos testes

Cada caso de teste deve apresentar:

- Identificação e título;
- Objetivo;
- Pré-condições;
- Passos para execução;
- Resultado esperado;
- Resultado observado;
- Status;
- Responsável pela execução;
- Link das evidências;
- Observações, quando necessário.

Os casos de teste são identificados pela sigla **CT**, seguida de numeração sequencial, permitindo sua organização e rastreabilidade.

## Evidências

As evidências das execuções são registradas por meio de capturas de tela e gravações, incluindo links do Jam.dev disponibilizados na documentação dos respectivos testes.

## Ferramentas utilizadas

- **SIFIT:** sistema avaliado;
- **Jam.dev:** captura de evidências;
- **Git e GitHub:** versionamento e organização da documentação;
- **Markdown:** elaboração dos documentos.
