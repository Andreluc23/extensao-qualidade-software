# CT038 - Busca de cliente por nome

## Objetivo
Verificar se a busca por nome retorna os clientes correspondentes.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Clientes.

## Passos para execução
1. Acessar o menu Clientes e selecionar Status "Todos".
2. Digitar "QA Felipe" no campo Nome.
3. Clicar em "Buscar".

## Resultado esperado
O sistema deve listar apenas os clientes que contêm o texto informado no nome.

## Resultado obtido
O sistema retornou apenas os clientes 432 (QA Felipe Teste Editado) e 434 (QA Felipe Cadastro Valido).

## Status
✅ Aprovado.
