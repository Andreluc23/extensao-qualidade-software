# CT009 - Check-in sem biometria

## Objetivo
Verificar se o sistema SIFIT permite registrar a entrada de um cliente pela opção "Sem biometria".

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.
- Cliente cadastrado no sistema.

## Passos para execução
1. Acessar o menu Check-in.
2. Clicar em "+ Check-in manual".
3. Selecionar a aba "Sem biometria".
4. Pesquisar e selecionar um cliente.
5. Verificar se o botão "Registrar entrada" está disponível.
6. Realizar o registro da entrada.

## Resultado esperado
O sistema deve permitir o registro de entrada de um cliente autorizado sem exigir autenticação biométrica.

## Resultado obtido
Na primeira tentativa, o botão de registro estava bloqueado. Em uma nova tentativa, foi possível concluir o check-in sem biometria com sucesso.

Não foi possível determinar se o bloqueio inicial era esperado, pois as condições daquela tentativa não foram totalmente esclarecidas.

## Status
✅ Aprovado — registro concluído na segunda tentativa.
