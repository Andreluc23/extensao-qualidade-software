# CT018 - Filtro Check-in pendente

## Objetivo
Verificar se o sistema SIFIT apresenta corretamente os registros com status de check-in pendente.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.
- Existência de registros com status pendente.

## Passos para execução
1. Acessar o menu Check-in.
2. Selecionar a aba "Todos".
3. Observar os registros e seus status.
4. Selecionar a aba "Check-in pendente".
5. Verificar os registros apresentados.

## Resultado esperado
O sistema deve apresentar os registros com status "Pendente", sem incluir registros de outras situações.

## Resultado obtido
A aba "Todos" apresentou cinco registros, todos com status "Pendente". Ao acessar "Check-in pendente", o sistema manteve os cinco registros correspondentes.

Não foi possível verificar a exclusão de registros com outros status, pois não havia exemplos disponíveis.

## Status
Aprovado para os registros disponíveis.
