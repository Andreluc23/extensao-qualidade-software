# CT006 - Realizar check-in manual

## Objetivo
Verificar se o sistema SIFIT permite localizar um cliente e registrar sua entrada manualmente.

## Pré-condições
- Usuário autenticado no sistema.
- Cliente cadastrado no SIFIT.
- Acesso ao módulo Check-ins.

## Passos para execução
1. Acessar o menu "Check-in".
2. Clicar em "+ Check-in manual".
3. Pesquisar um cliente pelo nome.
4. Selecionar o cliente encontrado.
5. Verificar se o sistema permite realizar o check-in.
6. Clicar em "Registrar entrada".
7. Conferir se o registro aparece na listagem.

## Resultado obtido

O sistema permitiu realizar a busca do cliente pelo nome, apresentou suas informações e exibiu a mensagem "Cliente liberado para realizar o check-in".

Após selecionar o cliente, o procedimento de registro da entrada foi concluído com sucesso.
