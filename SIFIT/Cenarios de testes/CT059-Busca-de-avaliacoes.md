# CT059 - Busca de avaliações

## Objetivo
Verificar se a busca de avaliações por nome funciona.

## Pré-condições
- Usuário autenticado no SIFIT.
- Avaliação cadastrada (ex.: #99).

## Passos para execução
1. Acessar o menu Avaliações.
2. Digitar "QA Felipe" no campo Nome.
3. Manter Status "Todos" e clicar em "Buscar".

## Resultado esperado
O sistema deve exibir apenas as avaliações do aluno pesquisado.

## Resultado obtido
O sistema exibiu apenas a avaliação #99 (QA Felipe Cadastro Valido).

## Status
✅ Aprovado.
