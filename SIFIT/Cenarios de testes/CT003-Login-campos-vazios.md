# CT003 - Login com campos vazios

## Objetivo
Verificar se o sistema impede a autenticação quando os campos de login e senha não são preenchidos.

## Pré-condições
- Sistema SIFIT disponível.
- Usuário na tela de login.

## Passos para execução
1. Acessar a página de login do SIFIT.
2. Deixar o campo Login vazio.
3. Deixar o campo Senha vazio.
4. Clicar no botão "Entrar".

## Resultado esperado
O sistema deve impedir o acesso e informar que os campos obrigatórios precisam ser preenchidos.

## Resultado obtido
*A preencher após a execução do teste.*
