# CT013 - Busca por nome no Check-in

## Objetivo
Verificar se o sistema SIFIT permite localizar registros de check-in utilizando o nome do cliente.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.
- Existência de registros de clientes na listagem.

## Passos para execução
1. Acessar o menu Check-in.
2. Localizar o campo de pesquisa.
3. Informar o nome de um cliente cadastrado.
4. Verificar os resultados apresentados na listagem.

## Resultado esperado
O sistema deve filtrar a listagem e apresentar somente os registros correspondentes ao nome pesquisado.

## Resultado obtido
A listagem inicialmente apresentava três clientes. Após informar o termo "leoni", o sistema filtrou os resultados e apresentou somente o cliente correspondente à pesquisa.

## Status
Aprovado.
