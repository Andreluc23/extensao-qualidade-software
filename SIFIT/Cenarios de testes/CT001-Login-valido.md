# CT001 - Login com credenciais válidas

## Objetivo

Validar se o sistema SIFIT permite o acesso de um usuário com credenciais válidas.

## Pré-condições

- Usuário previamente cadastrado no sistema.
- Usuário com login e senha válidos.
- Sistema SIFIT disponível para acesso.

## Passos para execução

1. Acessar a página de login do SIFIT.
2. Informar um login válido.
3. Informar uma senha válida.
4. Clicar no botão "Entrar".

## Resultado esperado

O sistema deve autenticar o usuário e direcioná-lo para a página inicial.

## Resultado obtido

O usuário foi autenticado com sucesso e direcionado para a página inicial do sistema.
