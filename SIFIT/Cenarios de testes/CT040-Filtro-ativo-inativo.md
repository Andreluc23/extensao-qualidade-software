# CT040 - Filtro de clientes Ativo/Inativo

## Objetivo
Verificar se o filtro de status exibe apenas clientes com o status escolhido.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Clientes.

## Passos para execução
1. Acessar o menu Clientes.
2. Selecionar Status "Inativo" e clicar em "Buscar".
3. Conferir a coluna Status da listagem.

## Resultado esperado
A listagem deve mostrar somente clientes com o status selecionado.

## Resultado obtido
Foram exibidos apenas clientes com status "inativo".

## Status
✅ Aprovado.
