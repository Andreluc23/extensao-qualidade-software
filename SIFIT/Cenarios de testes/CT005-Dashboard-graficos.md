# CT005 - Visualização dos gráficos do Dashboard

## Objetivo
Verificar se os gráficos do Dashboard apresentam informações adicionais ao posicionar o mouse sobre os dados.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Dashboard.

## Passos para execução
1. Acessar o menu "Dashboard".
2. Localizar os gráficos disponíveis.
3. Posicionar o mouse sobre as barras dos gráficos.
4. Repetir o procedimento nos gráficos de setores.
5. Verificar se as informações são apresentadas.

## Resultado esperado
O sistema deve exibir informações relacionadas aos dados representados nos gráficos ao posicionar o mouse sobre eles.

## Resultado obtido
Durante o teste, foram exibidas informações adicionais ao passar o mouse sobre diferentes gráficos do Dashboard, permitindo consultar os dados representados.
