# CT010 - Entrada rápida com código válido

## Objetivo
Verificar se o sistema SIFIT permite realizar o check-in de um cliente utilizando seu código na funcionalidade de Entrada rápida.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.
- Cliente cadastrado com código válido e autorizado a realizar check-in.

## Passos para execução
1. Acessar o menu Check-in.
2. Localizar a funcionalidade "Entrada rápida".
3. Informar o código de um cliente cadastrado.
4. Confirmar a entrada.
5. Verificar o resultado apresentado pelo sistema.

## Resultado esperado
O sistema deve identificar o cliente pelo código informado e permitir o registro de sua entrada.

## Resultado obtido
O sistema identificou corretamente o cliente pelo código informado e concluiu o registro do check-in com sucesso.

## Status
✅ Aprovado.
