# CT012 - Entrada rápida com código vazio

## Objetivo
Verificar o comportamento do SIFIT ao tentar realizar um check-in pela funcionalidade Entrada rápida sem informar o código do cliente.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.

## Passos para execução
1. Acessar o menu Check-in.
2. Localizar a funcionalidade "Entrada rápida".
3. Manter o campo de código vazio.
4. Tentar registrar a entrada.
5. Observar o comportamento do sistema.

## Resultado esperado
O sistema deve impedir o registro de entrada sem um código de cliente válido.

## Resultado obtido
Ao tentar registrar a entrada sem preencher o campo de código, o botão não apresentou resposta e nenhum check-in foi realizado.

## Status
Aprovado — o sistema impediu o registro sem código.
