# CT084 - Consistência entre status e valor pago

## Objetivo

Verificar consistência entre status e valor pago.

## Pré-condições

Sessão autenticada no SIFIT Alfa. Execução em 19/11/2026.

## Passos para execução

Em Contas a Pagar, filtre o status Pago pelo vencimento de 01/11/2026 a 30/11/2026.

## Resultado esperado

Os registros pagos devem apresentar o valor efetivamente pago.

## Resultado obtido
