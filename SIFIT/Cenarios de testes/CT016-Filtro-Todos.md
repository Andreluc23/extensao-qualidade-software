# CT016 - Filtro Todos no Check-in

## Objetivo
Verificar se a aba "Todos" apresenta os registros de check-in disponíveis, sem aplicar um filtro específico de situação.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.
- Existência de registros de check-in.

## Passos para execução
1. Acessar o menu Check-in.
2. Selecionar a aba "Todos".
3. Observar os registros apresentados na listagem.
4. Conferir a quantidade de registros exibidos.

## Resultado esperado
O sistema deve apresentar os registros de check-in disponíveis, independentemente da situação.

## Resultado obtido
A aba "Todos" apresentou três registros na listagem, correspondentes à quantidade indicada no card "Check-ins hoje".

Todos os registros exibidos estavam com a situação "Pendente", portanto não foi possível verificar o comportamento do filtro com situações diferentes.

## Status
Aprovado para a exibição dos registros disponíveis.
