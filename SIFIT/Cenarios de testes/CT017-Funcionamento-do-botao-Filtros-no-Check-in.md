# CT017 - Funcionamento do botão Filtros no Check-in

## Objetivo
Verificar se o botão "Filtros" permite acessar opções adicionais de filtragem dos registros de check-in.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.

## Passos para execução
1. Acessar o menu Check-in.
2. Localizar o botão "Filtros".
3. Clicar no botão.
4. Verificar se o sistema apresenta opções de filtragem ou alguma resposta visual.

## Resultado esperado
O sistema deve disponibilizar as opções de filtragem ou informar claramente quando a funcionalidade estiver indisponível.

## Resultado obtido
O usuário relatou que o botão não apresenta resposta ao ser acionado. A gravação enviada mostra a tela de Check-in, mas não permite confirmar a tentativa de acionamento do botão.

## Status
Pendente de confirmação — possível falha de funcionamento.
