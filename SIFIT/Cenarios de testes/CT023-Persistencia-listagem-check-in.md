# CT023 - Persistência da listagem após atualização

## Objetivo
Verificar se os registros de check-in permanecem disponíveis após atualizar a página do navegador.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.
- Existência de registros de entrada.

## Passos para execução
1. Acessar o menu Check-in.
2. Observar os registros apresentados na listagem.
3. Conferir o indicador "Check-ins hoje".
4. Atualizar a página pelo navegador.
5. Verificar se os registros permanecem disponíveis.
6. Conferir se o indicador mantém o valor correto.

## Resultado esperado
O sistema deve manter os registros de check-in após a atualização da página, sem perda das informações apresentadas.

## Resultado obtido
Antes da atualização, a listagem apresentava sete registros de check-in.

Após atualizar a página, os mesmos sete registros permaneceram visíveis, com seus respectivos horários de entrada.

O indicador "Check-ins hoje" também permaneceu com o valor 7.

## Status
Aprovado.
