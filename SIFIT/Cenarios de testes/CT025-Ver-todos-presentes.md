# CT025 - Ver todos os clientes presentes

## Objetivo
Verificar se a opção "Ver todos", localizada no painel "Presentes agora", permite consultar os clientes presentes na academia.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.

## Passos para execução
1. Acessar o menu Check-in.
2. Localizar o painel "Presentes agora".
3. Observar a quantidade de clientes presentes.
4. Clicar na opção "Ver todos".
5. Verificar a resposta do sistema.

## Resultado esperado
O sistema deve direcionar o usuário à consulta de clientes presentes ou apresentar uma resposta clara, mesmo quando não houver clientes presentes.

## Resultado obtido
O indicador "Presentes agora" apresentava 0 clientes.

Após acionar "Ver todos", a página permaneceu na aba "Todos", sem apresentar uma janela, mensagem ou mudança perceptível na listagem.

## Status
Reprovado provisoriamente — possível ausência de resposta da funcionalidade.
