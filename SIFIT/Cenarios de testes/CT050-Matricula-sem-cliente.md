# CT050 - Matrícula sem cliente

## Objetivo
Verificar se o sistema impede salvar uma matrícula sem cliente.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Matrículas.

## Passos para execução
1. Acessar Matrículas > "Cadastrar Matrícula".
2. Não selecionar nenhum cliente.
3. Clicar em "Salvar".

## Resultado esperado
O sistema deve impedir o cadastro e informar que é necessário selecionar um cliente.

## Resultado obtido
O sistema exibiu o aviso "Selecione o cliente!" e não salvou a matrícula.

## Status
✅ Aprovado.
