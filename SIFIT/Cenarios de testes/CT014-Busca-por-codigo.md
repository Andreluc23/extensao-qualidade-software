# CT014 - Busca por código no Check-in

## Objetivo
Verificar se o sistema SIFIT permite localizar registros de check-in utilizando o código do cliente.

## Pré-condições
- Usuário autenticado no SIFIT.
- Acesso ao módulo Check-in.
- Existência de clientes na listagem.

## Passos para execução
1. Acessar o menu Check-in.
2. Localizar o campo de pesquisa da listagem.
3. Informar o código de um cliente.
4. Verificar os resultados apresentados.

## Resultado esperado
O sistema deve filtrar a listagem e apresentar o registro correspondente ao código informado.

## Resultado obtido
Ao pesquisar pelo código 431, o sistema apresentou somente o registro correspondente ao cliente Gabriel Abreu.

## Status
Aprovado.
