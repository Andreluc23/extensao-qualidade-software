# BUG018 - Tela apresenta contraste ruim, dificultando a leitura

## Módulo

Tipos de Documentos

## Objetivo

Documentar problema de acessibilidade e usabilidade causado pelo baixo contraste entre texto e fundo na tela de Tipos de Documentos.

## Pré-condições

- Usuário autenticado no sistema SIFIT.
- Acesso ao módulo **Tipos de Documentos**.

## Passos para reprodução

1. Navegar até o menu Configurações/Cadastros > **Tipos de Documentos**.
2. Observar os rótulos, textos da tabela e elementos visuais da interface.

## Resultado esperado

A interface deve apresentar contraste adequado entre a cor da fonte e a cor de fundo (atendendo às diretrizes WCAG), garantindo leitura confortável.

## Resultado obtido

A tela apresenta contraste muito baixo entre texto e fundo, dificultando a leitura das informações.

## Status

🔍 Identificado

## Observação

Impacta diretamente a usabilidade e acessibilidade visual do sistema.
