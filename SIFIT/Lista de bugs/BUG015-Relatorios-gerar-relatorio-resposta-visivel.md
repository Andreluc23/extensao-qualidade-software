# BUG015 - Botão “Gerar Relatório” apresenta resposta visível

## Módulo

Relatórios

## Objetivo

Documentar e confirmar o comportamento atípico apresentado pela interface ao acionar o botão “Gerar Relatório”.

## Pré-condições

- Usuário autenticado no sistema SIFIT.
- Acesso ao módulo **Relatórios**.

## Passos para reprodução

1. Navegar até o menu **Relatórios**.
2. Selecionar um tipo de relatório e preencher os filtros desejados.
3. Clicar no botão **“Gerar Relatório”**.
4. Observar o retorno apresentado na tela ou no download.

## Resultado esperado

O sistema deve processar a solicitação e exibir o relatório formatado para visualização ou iniciar o download do arquivo de forma limpa.

## Resultado obtido

Ao clicar em **“Gerar Relatório”**, o sistema apresenta resposta visível inadequada/sem retorno esperado na interface.

## Status

⚠️ A confirmar

## Observação

Status marcado como *A confirmar* — necessário validar em diferentes tipos de relatórios do módulo.
